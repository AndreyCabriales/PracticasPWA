Paquete de Iconos PNG Integrados

Requeridos por la especificación PWA (mínimo 192x192 px para pantallas estándar y 512x512 px para Splash Screen y pantallas HiDPI):

icon-192x192.png 192 × 192 px Uso: Pantalla de inicio móvil y listas de aplicaciones
icon-512x512.png 512 × 512 px Uso: Splash Screen nativa y tiendas de aplicaciones

Cómo verificar en Google Chrome DevTools

  1. Abre esta página en Chrome (mediante http://localhost/... o un servidor local).
  2. Presiona F12 o Ctrl + Shift + I para abrir las Herramientas de Desarrollador.
  3. Ve a la pestaña superior Application (o Aplicación).
  4. En la barra lateral izquierda, bajo Application, haz clic en Manifest.
  5. Observa cómo Chrome detecta automáticamente todos los valores: Name, Short Name, Start URL, Theme color, Background color y los dos iconos.
  6. Haz clic en el enlace "Install app" que Chrome DevTools muestra para probar el diálogo de instalación.
