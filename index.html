Prácticas de Progressive Web Apps (PWA)

Laboratorio Integral de PWA

Cinco ejercicios modulares e independientes cubriendo Manifest, App Shell con Splash Screen, Service Workers, Cache API (Cache-First) y Manejo de Estado Offline con Fallback.

Ejercicio 01

Web App Manifest & Metadatos

Configuración del archivo manifest.json enlazado al HTML base y metadatos de instalación en el dispositivo.

  • Propiedades: name, short_name, start_url.
  • Modo de visualización display: standalone.
  • Colores theme_color y background_color.
  • Iconos PNG: 192x192 px y 512x512 px.
  • Captura del evento beforeinstallprompt.

Ejercicio 02

App Shell & Splash Screen Nativa

Arquitectura de interfaz base ultra rápida y responsiva con visualización de la Splash Screen nativa del sistema operativo.

  • Diseño responsivo: Header fijo con branding.
  • Menú de navegación: Sidebar desktop, Drawer & Bottom Nav móvil.
  • Contenedor principal <main> para contenido dinámico.
  • Skeleton Loading sin parpadeo.
  • Simulador y verificación en DevTools de Splash Screen.

Ejercicio 03

Service Worker & Almacenamiento

Ciclo de vida del Service Worker, estrategias de caché y persistencia de datos asíncrona con IndexedDB.

  • Registro, install (skipWaiting) y activate limpia.
  • Purga automática de cachés antiguas.
  • Estrategias combinadas para estáticos y dinámicos.
  • Persistencia asíncrona CRUD con IndexedDB offline.
  • Panel de control de almacenamiento en vivo.
Abrir Ejercicio 3 →
Ejercicio 04

Cache API & Estrategia Cache-First

Creación de memoria caché con la Cache API durante install, guardado del App Shell y entrega inmediata con Cache-First en fetch.

  • Creación de caché en install con caches.open.
  • Precaching del App Shell (HTML, CSS, JS, iconos).
  • Intercepción en fetch sirviendo primero desde caché.
  • Fallback a red solo si el recurso no existe en caché.
  • Medidor de latencia en vivo (~0 ms de tiempo de respuesta).

Ejercicio 05

Interceptor Fetch & Fallback Offline

Programación de respuesta alternativa ante pérdida de conexión y plantilla personalizada de "Modo Sin Conexión" (offline.html).

  • Intercepción de fallos de red en el evento fetch.
  • Entrega de la plantilla personalizada offline.html.
  • Sustitución del error de dinosaurio genérico del navegador.
  • Fallbacks dedicados para navegación HTML, APIs JSON e imágenes.
  • Laboratorio de pruebas con rutas cacheadas y no cacheadas.

🚀 Cómo ejecutar y verificar en tu entorno local (XAMPP / Navegador)

1
Inicia Apache en XAMPP: Abre el panel de control de XAMPP y haz clic en Start junto a Apache.
2
Abre tu navegador (Google Chrome): Ingresa a la URL: http://localhost/PrácticasPWA/ (Nota: los Service Workers y Web App Manifest requieren un origen seguro https:// o http://localhost para operar).
3
Abre Chrome DevTools (F12): Explora las pestañas Application (Manifest, Service Workers, Storage, Cache Storage, IndexedDB) y Network (simulación de Offline throttling).
